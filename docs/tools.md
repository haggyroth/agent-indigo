# Tools

The model acts only through these tools. Every one is a **skill**: deterministic code that takes an intent, drives the emulator, verifies the outcome in memory, and either succeeds or fails cleanly with a message the model can act on (see [architecture](architecture.md#skills-not-button-presses)).

The model is only **offered the tools that fit the screen** (`agent.tools.tools_for`): about 1.2k tokens of schema in battle, 3.9k on the overworld, and everything in menus, dialogs and transitions. Encounters — wild or trainer — end `go_to`, `grind` and the quest tools, so the model plays every battle itself.

The table below is generated from `agent/tools.py` — run `python tools/gen_tool_docs.py` after changing a tool; a test keeps it (and the copy in `CLAUDE.md`) current. `?` marks an optional argument.
